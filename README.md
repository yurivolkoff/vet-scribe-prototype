# Прототип: предложения из записи приёма

Кликабельный прототип интерфейса для ветеринарной CRM: врач записывает приём, сервис предлагает, что внести в поля, врач принимает или убирает предложения.

Все данные в прототипе вымышленные. Звук не записывается и никуда не отправляется: прототип только запрашивает доступ к микрофону, чтобы показать уровень сигнала.
